# Trumpagotchi — first FM-1 release

A burger-powered virtual pet with an ego problem and surprisingly good bongo timing.

- Feed, Praise, Clean and Rest on four illuminated care keys.
- Pentatonic keyboard instrument and happy-pet bongo accompaniment.
- Twelve recorded reactions, captions, news watching and stress eating.
- Five-minute days, daytime naps and fast overnight sleep with full energy at dawn.
- Persistent progress, manual SAVE, autosave, pause and three-meter Game Over.
- HOME Status and GLO Start Over; dry keyboard sound.

Firmware identity: **FM-1_710**. This exact package was installed and its restart verified on an M-VAVE FM-1. Other hardware units, starting firmware and computer setups are not exhaustively tested.

Download **trumpagotchi.fwsc** and **trumpagotchi-source.zip** from the assets below. Follow the included README to install. **trumpagotchi-quick-start.pdf** is the one-page controls guide; the PNG is an image copy.
